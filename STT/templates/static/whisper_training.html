Whisper Model Fine-Tuning

Configure and train your custom Whisper model with your own dataset

Dataset Structure Requirements

Your dataset must follow this specific structure for successful fine-tuning:

my_dataset/ ├── train.csv ├── test.csv ├── audio_file_1.wav ├── audio_file_2.wav ├── audio_file_3.wav └── ... (more audio files)
CSV File Format

Both train.csv and test.csv must contain exactly these columns:

audio,sentence audio_file_1.wav,Hello, this is a sample audio file audio_file_2.wav,The weather is nice today audio_file_3.wav,How are you doing?
Important Requirements:
  • Column names: Must be exactly "audio" and "sentence" (case-sensitive)
  • Audio paths: Relative paths from the dataset directory
  • Audio format: WAV, MP3, or other common audio formats
  • Audio quality: 16kHz sample rate recommended (will be converted automatically)
  • Text encoding: UTF-8 encoding for special characters
  • File size: Keep individual audio files under 30 seconds for best results
Example Dataset Creation

Here's how to create a proper dataset from your audio files:

# Python script to create dataset import pandas as pd import os # Create train.csv train_data = [ {"audio": "sample1.wav", "sentence": "Hello world"}, {"audio": "sample2.wav", "sentence": "Good morning"}, {"audio": "sample3.wav", "sentence": "How are you?"} ] train_df = pd.DataFrame(train_data) train_df.to_csv("my_dataset/train.csv", index=False) # Create test.csv test_data = [ {"audio": "test1.wav", "sentence": "This is a test"}, {"audio": "test2.wav", "sentence": "Fine tuning example"} ] test_df = pd.DataFrame(test_data) test_df.to_csv("my_dataset/test.csv", index=False)
